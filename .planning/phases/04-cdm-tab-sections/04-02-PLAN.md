Input fields (inside dialog.Inset):
- Spell ID: `CreateFrame("EditBox", nil, dialog.Inset, "InputBoxTemplate")`, size 160x22

  - Initially empty string

  - OnClick validation per D-11:
    - `local spellID = spellIdBox:GetNumber()` — if nil or <= 0: `errorLabel:SetText("Invalid Spell ID")`, return
    - `local duration = tonumber(durationBox:GetText())` — if nil or <= 0: `errorLabel:SetText("Invalid Duration")`, return
    - Call `ns:AddTrackedBuff(spellID, duration)`
    - Call `ns:RefreshTBTSections()`
    - `dialog:Hide()`

In `ns:RefreshTBTSections()`, for the "hidden" section ONLY, create/show a permanent delete zone frame BEFORE populating the item pool:
- Create once (not pooled): `ns.tbtDeleteZone = ns.tbtDeleteZone or CreateFrame("Frame", nil, ns.tbtSections.hidden.container)`
- Size: 38x38 per UI-SPEC delete-zone-size
- `layoutIndex = 0` so it appears first in the grid
- Background: `SetColorTexture(0.8, 0.1, 0.1, 0.4)` on BACKGROUND layer per UI-SPEC color table
- Centered atlas: `common-icon-redx` at 24x24 on OVERLAY layer per UI-SPEC delete-zone-icon
- Always visible when Not Displayed section is shown
- No tooltip, no hover effect in Phase 4 per UI-SPEC interaction contract
- Show it before `container:Layout()` so it occupies the first grid slot

**CRITICAL CONSTRAINTS:**
- Duration input must NOT use SetNumeric(true) — per Pitfall 4, this rejects decimals. Use plain text + tonumber() validation.
- Delete zone is visual-only in Phase 4. No drag handling. Phase 5 wires drag-drop.
- Dialog must be parented to CooldownViewerSettings (not UIParent) so it stays with the CDM window.
- ButtonFrameTemplate provides .Inset — anchor input fields to dialog.Inset, not dialog directly.
