Add `ns:SetBuffSection(spellID, section)` to BuffEngine.lua after the existing `ns:SetBuffEnabled` function (around line 159). Per D-16 and the UI-SPEC contract:

```lua
function ns:SetBuffSection(spellID, section)
    local entry = ns.db.trackedBuffs[spellID]
    if not entry then return end
    entry.section = section
    if ns.activeTimers[spellID] then
        ns.activeTimers[spellID].section = section
    end
    if section == "hidden" then
        ns.activeTimers[spellID] = nil
    end
    if ns.UpdateDisplay then
        ns:UpdateDisplay()
    end
end
```

This is a direct section setter that also syncs the active timer and clears it when hiding. It replaces the need to use `SetBuffDisplayMode` (which maps old "buff"/"bar" strings) for context menu actions.

**1. Section definition table** (per D-01 order):
```lua
local SECTION_DEFS = {
    { key = "bars",   title = "Tracked Bars" },
    { key = "buffs",  title = "Tracked Buffs" },
    { key = "hidden", title = "Not Displayed" },
    { key = "suggested", title = "Suggested" },
}
```

**2. Icon frame factory** (per UI-SPEC Component Inventory and RESEARCH "Icon frame setup"):
Create a local function `CreateIconFrame(parent)` that:
- Creates a 38x38 Frame
- Creates `f.Icon` texture (ARTWORK layer, SetAllPoints)
- Creates highlight texture (HIGHLIGHT layer, `Interface\Buttons\ButtonHilight-Square`, ADD blend mode)
- `EnableMouse(true)`
- OnEnter: shows GameTooltip with spell name (line 1), "Spell ID: {id}" (line 2), "Duration: {n}s" (line 3) per D-05
- OnLeave: hides GameTooltip
- OnMouseUp for right-click: calls `MenuUtil.CreateContextMenu` per D-14/D-15/D-16:
  - If sectionName == "bars": "Move to Buffs", "Hide", divider, "Remove"
  - If sectionName == "buffs": "Move to Bars", "Hide", divider, "Remove"
  - If sectionName == "hidden": "Move to Bars", "Move to Buffs", divider, "Remove"
  - If sectionName == "suggested": no context menu (right-click does nothing)
  - Each "Move to X" calls `ns:SetBuffSection(spellID, section)` then `ns:RefreshTBTSections()` per D-16/D-17
  - "Remove" calls `ns:RemoveTrackedBuff(spellID)` then `ns:RefreshTBTSections()`
- Returns the frame

**3. BuildTBTSection(parent, def)** function (per RESEARCH "Full section construction"):
- Creates `section = {}` table with `.frame`, `.header`, `.container`, `.itemPool`, `.collapsed = false`, `.key = def.key`
- `section.frame`: plain Frame parented to `parent`, width=300
- `section.header`: Button inheriting `ListHeaderThreeSliceTemplate`, anchored TOPLEFT+TOPRIGHT to section.frame
  - Size: (0, 22) per UI-SPEC header-height
  - `SetTitleColor(false, NORMAL_FONT_COLOR)` and `SetTitleColor(true, NORMAL_FONT_COLOR)`
  - `SetHeaderText(def.title)` per copywriting contract
  - `UpdateCollapsedState(false)`
  - `SetClickHandler`: toggles `section.collapsed`, calls `container:SetShown(not collapsed)`, calls `header:UpdateCollapsedState(collapsed)`, calls `ns:UpdateSectionHeight(section)` then `ns:UpdateScrollChildHeight()`
- `section.container`: Frame inheriting `GridLayoutFrame`, anchored TOPLEFT to header BOTTOMLEFT with offset (13, -8) per UI-SPEC container-indent and header-to-container
  - Width: 300, initial height: 46 (one row: 38 icon + 8 padding)
  - Set grid params: `childXPadding=8`, `childYPadding=8`, `isHorizontal=true`, `stride=7`, `layoutFramesGoingRight=true`, `layoutFramesGoingUp=false`, `alwaysUpdateLayout=true` per UI-SPEC icon-stride and icon-gap
- `section.itemPool`: `CreateFramePool("Frame", section.container)` with `CreateIconFrame` as the creation function
- Returns section table

**4. ns:BuildAllSections()** — called once from InitCDMTab after panel creation:
- Store sections in `ns.tbtSections = {}` keyed by section key
- Iterate SECTION_DEFS, call `BuildTBTSection(ns.tbtScrollChild, def)` for each
- Stack vertically: first section anchored TOPLEFT to ns.tbtScrollChild TOPLEFT (0,0), subsequent sections anchored TOPLEFT to previous section.frame BOTTOMLEFT (0, -12) per UI-SPEC section-gap
- Store in ns.tbtSections[def.key] = section

**5. ns:UpdateSectionHeight(section)** helper:
- If collapsed: `section.frame:SetHeight(22)` (header only)
- If expanded: `section.frame:SetHeight(22 + 8 + section.container:GetHeight())` — header + gap + container
- This is the section frame height including header + content

**6. ns:UpdateScrollChildHeight()** helper:
- Sum all section frame heights + (numSections - 1) * 12 gap
- `ns.tbtScrollChild:SetHeight(totalHeight)`
- Per RESEARCH Pitfall 5: scroll child height must be manually maintained

**7. ns:RefreshTBTSections()** — the single entry point for all section redraws (per UI-SPEC Section Refresh Contract):
- For each section in ns.tbtSections:
  - `section.itemPool:ReleaseAll()`
  - If section.key == "suggested": skip DB iteration (placeholder section for now)
  - Else: iterate `ns.db.trackedBuffs`, for each entry where `entry.section == section.key`:
    - `local item = section.itemPool:Acquire()`
    - `item.spellID = spellID`
    - `item.Icon:SetTexture(ns:GetSpellIcon(spellID))`
    - `item.sectionName = section.key`
    - `item.layoutIndex = spellID` (stable sort key)
    - `item:Show()`
  - `section.container:Layout()`
  - `ns:UpdateSectionHeight(section)`
- After all sections: `ns:UpdateScrollChildHeight()`

**8. Hook RefreshTBTSections to panel OnShow:**
In `ns:InitCDMTab()`, after existing panel setup, add:
```lua
ns:BuildAllSections()
ns.tbtPanel:HookScript("OnShow", function()
    ns:RefreshTBTSections()
end)
```
