# Phase 4 — UI Design Contract: CDM Tab Sections

> Visual and interaction contract for Phase 4. Generated by gsd-ui-researcher.
> This is a WoW Lua/XML addon — Blizzard UI templates replace a web design system.
> All measurements are WoW UI units (equivalent to pixels at 1x UI scale).

## Spacing Scale

WoW UI uses explicit pixel offsets. All values below are derived directly from
`CooldownViewerSettings.xml` and `CooldownViewerSettings.lua` source — TBT must
match them to feel native inside the CDM panel.

| Token | Value | Usage |
|-------|-------|-------|
| icon-size | 38px | Buff icon frame width and height — matches `CooldownViewerSettingsItemTemplate` |
| icon-gap | 8px | `childXPadding` and `childYPadding` on `GridLayoutFrame` — matches CDM Container |
| icon-stride | 7 | Icons per row in GridLayoutFrame — matches CDM's own category Container |
| header-height | 22px | `ListHeaderThreeSliceTemplate` button height — matches CDM category header |
| header-to-container | 8px (y=-8) | TOPLEFT Y offset: container TOPLEFT anchored to header BOTTOMLEFT, y=-8 |
| container-indent | 13px (x=13) | TOPLEFT X offset: container indented 13px from header left — matches CDM `CooldownViewerSettingsCategoryTemplate` Container anchor |
| section-gap | 12px (y=-12) | Vertical gap between stacked section frames — matches CDM `AddCategory` pattern |
| dialog-field-gap | 10px (y=-10) | Vertical gap between Spell ID and Duration edit boxes in Add dialog |
| dialog-label-gap | 6px (y=-6) | Gap between last edit box and error label in Add dialog |
| dialog-button-margin | 10px | Left/right inset for Add/Cancel buttons from dialog Inset edges |
| dialog-field-top | 16px (y=-16) | TOP offset of first edit box from dialog Inset top |
| delete-zone-size | 38px | Delete zone frame is 38x38 — occupies one icon slot in the grid |
| delete-zone-icon | 24px | Trash atlas icon centered within the delete zone frame |

Exceptions:
- Delete zone red tint alpha is 0.4 (rgba 0.8, 0.1, 0.1, 0.4) — not a spacing value but a fixed constant.
- Section gap from the first section to `ns.tbtScrollChild` TOPLEFT is 0 (no top padding; first section flush to scroll child top).

**Source:** `CooldownViewerSettings.xml` lines 115-128 (Container KeyValues, size, anchors);
RESEARCH.md "Architecture Patterns" section; D-06 from CONTEXT.md.

## Typography

WoW font objects are used, not raw size/weight values.

| Role | WoW Font Object | Usage |
|------|-----------------|-------|
| Section header title | `NORMAL_FONT_COLOR` tint on `ListHeaderThreeSliceMixin` title | Set via `header:SetTitleColor(false, NORMAL_FONT_COLOR)` and `header:SetTitleColor(true, NORMAL_FONT_COLOR)` |
| Dialog title bar | `ButtonFrameTemplate` built-in title FontString | Set via `dialog:SetTitle("Add Tracked Buff")` |
| Dialog label text | `GameFontHighlightSmall` | "Spell ID:" and "Duration (sec):" labels above each input box |
| Error message | `GameFontRed` | Inline error below Duration field; `errorLabel:SetText("Invalid Spell ID")` / `"Invalid Duration"` |
| Add button text | `UIPanelButtonTemplate` built-in | "Add" |
| Cancel button text | `UIPanelButtonTemplate` built-in | "Cancel" |
| Add section button text | `UIPanelButtonTemplate` built-in | "Add Buff" |
| Tooltip title | `GameTooltipTextLeft1` (via `GameTooltip:SetSpellByID`) | Spell name — populated automatically from `C_Spell.GetSpellInfo` |
| Tooltip body line 1 | `GameTooltipTextLeft2` | "Spell ID: {spellID}" |
| Tooltip body line 2 | `GameTooltipTextLeft3` | "Duration: {duration}s" |

Phase 4 introduces no new font objects beyond those listed. All fonts are
standard Blizzard global font objects — no custom font definitions.

**Source:** RESEARCH.md Standard Stack (API table); D-05, D-09, D-11 from CONTEXT.md;
Phase 3 UI-SPEC (font objects carried forward).

## Color

WoW addons use atlas textures and color constants — not hex values.

| Role | Treatment | Usage |
|------|-----------|-------|
| Section header (inactive) | `ListHeaderThreeSliceTemplate` default atlas (`Interface\Buttons\UI-ListBox-Highlight2`) | All four section headers at rest — provided automatically by template |
| Section header (hover) | Highlight layer active — provided by `ListHeaderThreeSliceTemplate` | Mouse-over state — no code needed |
| Section header (collapsed) | `Right` atlas swapped from down-arrow to right-arrow via `UpdateCollapsedState(true)` | Collapsed section visual cue — handled by `ListHeaderThreeSliceMixin` |
| Icon frame (hover) | `ButtonHilight-Square` texture with `ADD` alpha mode on Highlight layer | Matches `CooldownViewerSettingsItemTemplate` exactly — shows on `OnEnter` |
| Delete zone background | `SetColorTexture(0.8, 0.1, 0.1, 0.4)` on BACKGROUND layer | Red-tinted placeholder inside Not Displayed grid; always visible |
| Delete zone icon | Atlas `common-icon-redx` centered at 24x24 on OVERLAY layer | Trash/X visual cue inside delete zone frame |
| Panel surface | Inherited from Phase 3 — `BackdropTemplate` with `SetBackdropColor(0, 0, 0, 0.9)` | No change from Phase 3 |
| Dialog surface | `ButtonFrameTemplate` built-in Blizzard dialog background | Add Buff dialog — standard WoW modal appearance |
| Error text | `GameFontRed` (red color built into font object) | Inline validation error in Add dialog |

Accent reserved for: Delete zone background (red tint) — used exclusively to
signal "destructive drop target" to the user. No other element in Phase 4 uses
a colored tint. All other interactive states use Blizzard-provided highlight
textures from templates.

**Source:** `CooldownViewerSettings.xml` lines 17-33 (item highlight); RESEARCH.md
"Delete Drop Zone" pattern; D-13 from CONTEXT.md.

## Interaction Contract

### Section Collapse/Expand

| Interaction | Expected Result |
|-------------|----------------|
| User clicks section header | `section.collapsed` toggles. `container:SetShown(not section.collapsed)`. `header:UpdateCollapsedState(section.collapsed)`. Arrow atlas swaps direction. |
| Section starts collapsed | `collapsed = false` on init — all four sections start expanded. |
| Section has no icons | Container is shown but empty. Section is still collapsible. No "empty" placeholder text. |
| Collapse/expand animation | Instant show/hide — no tween. `SetShown` is immediate. |

**Source:** D-03 from CONTEXT.md; RESEARCH.md Pitfall 2 (alwaysUpdateLayout).

### Buff Icon Display

| Interaction | Expected Result |
|-------------|----------------|
| User opens TBT tab | `ns:RefreshTBTSections()` called. All four section pools released and repopulated from `ns.db.trackedBuffs`. `container:Layout()` called per section. |
| User mouses over buff icon | `GameTooltip:SetOwner(self, "ANCHOR_RIGHT")`. Lines added: spell name (line 1), "Spell ID: {id}" (line 2), "Duration: {n}s" (line 3). `GameTooltip:Show()`. |
| User mouses off buff icon | `GameTooltip:Hide()`. |
| Icon texture fails to resolve | `item.Icon:SetTexture(134400)` — fallback to question mark icon (Interface\Icons\INV_Misc_QuestionMark). |

**Source:** D-04, D-05 from CONTEXT.md; RESEARCH.md "Populating Icons from DB" pattern.

### Right-Click Context Menu

| Interaction | Expected Result |
|-------------|----------------|
| User right-clicks icon in Tracked Bars | Context menu shows: "Move to Buffs", "Hide", divider, "Remove" |
| User right-clicks icon in Tracked Buffs | Context menu shows: "Move to Bars", "Hide", divider, "Remove" |
| User right-clicks icon in Not Displayed | Context menu shows: "Move to Bars", "Move to Buffs", divider, "Remove" |
| User right-clicks icon in Suggested | No context menu — `OnMouseUp` takes no action for right-click in Suggested section |
| User selects "Move to Bars" | `ns:SetBuffSection(spellID, "bars")`. `ns:RefreshTBTSections()`. `ns:UpdateDisplay()` called inside SetBuffSection. |
| User selects "Move to Buffs" | `ns:SetBuffSection(spellID, "buffs")`. `ns:RefreshTBTSections()`. |
| User selects "Hide" | `ns:SetBuffSection(spellID, "hidden")`. `ns:RefreshTBTSections()`. |
| User selects "Remove" | `ns:RemoveTrackedBuff(spellID)`. `ns:RefreshTBTSections()`. |
| Context menu opens | `MenuUtil.CreateContextMenu(iconFrame, buildFn)`. Sound plays automatically via Blizzard Menu system. |

**Source:** D-14, D-15, D-16, D-17 from CONTEXT.md; RESEARCH.md "Right-Click Context Menu" pattern.

### Add Buff Dialog

| Interaction | Expected Result |
|-------------|----------------|
| User clicks "Add Buff" button | `ns.tbtAddDialog:Show()`. Both input boxes cleared. Error label cleared. Spell ID box focused via `spellIdBox:SetFocus()`. |
| User enters non-numeric or empty Spell ID, clicks Add | Error label shows "Invalid Spell ID". Dialog stays open. No entry created. |
| User enters zero or negative Spell ID, clicks Add | Error label shows "Invalid Spell ID". Dialog stays open. |
| User enters non-numeric or empty Duration, clicks Add | Error label shows "Invalid Duration". Dialog stays open. |
| User enters zero or negative Duration, clicks Add | Error label shows "Invalid Duration". Dialog stays open. |
| User enters valid Spell ID + valid Duration, clicks Add | `ns:AddTrackedBuff(spellID, duration)` called. `ns:RefreshTBTSections()` called. Dialog hides. New buff appears in Not Displayed section. |
| User clicks Cancel | Dialog hides. No entry created. Input values discarded. |
| User presses Escape | Dialog hides (registered in `UISpecialFrames`). No entry created. |
| Dialog positioning | Centered on `CooldownViewerSettings` frame. Does not move with the CDM window while open (fixed anchor). |

**Source:** D-09, D-10, D-11 from CONTEXT.md; RESEARCH.md "Add Dialog" pattern; Pitfall 4 (SetNumeric and decimals).

### Delete Drop Zone

| Interaction | Expected Result |
|-------------|----------------|
| User views Not Displayed section | Delete zone is always visible as one slot in the icon grid, showing a red-tinted frame with centered X/trash atlas. |
| User mouses over delete zone | No tooltip. No hover effect in Phase 4. (Phase 5 adds drag-enter highlight.) |
| User attempts to drag icon to delete zone | No effect in Phase 4 — drag is not implemented. Zone is visual-only. |
| Delete zone position in grid | Always first slot (layoutIndex=0 or equivalent). Populated before item pool acquire so it appears at the start of the grid. |

**Source:** D-12, D-13 from CONTEXT.md; RESEARCH.md "Delete Drop Zone" pattern.

### Section Refresh Contract

`ns:RefreshTBTSections()` is the single entry point for all section redraws:

1. For each section: `section.itemPool:ReleaseAll()`
2. Iterate `ns.db.trackedBuffs`, populate matching section pools
3. Call `container:Layout()` per section
4. Call `ns.tbtScrollChild:SetHeight(totalHeight)` with calculated sum of all section heights

`ns:RefreshTBTSections()` is called:
- When the TBT tab is shown (`ns.tbtPanel:SetScript("OnShow", ...)`)
- After any context menu action (Move, Hide, Remove)
- After Add dialog confirms a new buff
- After any future drag-drop action (Phase 5 will hook this)

**Source:** RESEARCH.md "Populating Icons from DB"; Pitfall 5 (tbtScrollChild height).

## New BuffEngine API Required

The following function does not yet exist and must be added to `BuffEngine.lua`
as a Wave 0 task before any section UI work:

```lua
function ns:SetBuffSection(spellID, section)
    local entry = ns.db.trackedBuffs[spellID]
    if not entry then return end
    entry.section = section
    if ns.activeTimers[spellID] then
        ns.activeTimers[spellID].section = section
    end
    if section == "hidden" then
        ns.activeTimers[spellID] = nil
    end
    if ns.UpdateDisplay then
        ns:UpdateDisplay()
    end
end
```

**Source:** RESEARCH.md "Missing BuffEngine API: ns:SetBuffSection".
