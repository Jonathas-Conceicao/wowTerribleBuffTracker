  <how-to-verify>
    **Perform these tests in the order listed. Report PASS / FAIL / SKIP for each.**

    ### Load smoke test (prerequisite — if this fails, abort and report)
    1. Launch WoW (or `/reload` if already in game).
    2. Watch the chat for TBT load message: `|cff00ccffTerribleBuffTracker|r loaded. Type |cff00ff00/tbt|r ...`.
    3. No red Lua error dialogs should appear during load or the first 10 seconds of gameplay.
    4. Expected: no errors; load message appears.

    ### Enable debug logging for the session
    ```
    /tbt debug
    ```
    Chat should respond: `|cff00ccffTBT|r: Debug logging |cff00ff00ON|r`

    ### Test 1 — User-spell regression (PROV-02 / Phase 17-18 guard)
    1. Have a tracked user-spell in your `bars` section (e.g. a buff from `/tbt`).
    2. Cast it.
    3. Expected: bar appears, countdown runs.
    4. Verify the buff drops or expires and the timer disappears.
    5. Report: PASS / FAIL.

    ### Test 2 — Trinket regression (LIFE-01 / Phase 18 guard)
    1. Have a tracked trinket entry (key="trinket") in a visible section.
    2. Equip one of the tracked on-use trinkets (see Providers.lua TRINKET_SPELLS list) and use it.
    3. Expected: trinket timer appears with correct icon + duration + label.
    4. Re-use after cooldown — timer should restart (Phase 18 D-03 replace-on-reproc).
    5. Report: PASS / FAIL.

    ### Test 3 — Pot regression (LIFE-01 / Phase 18 guard)
    1. Have a tracked pot entry (key="pot") in a visible section.
    2. Consume one of the tracked damage potions.
    3. Expected: pot timer appears with correct icon + duration + label.
    4. Report: PASS / FAIL / SKIP (if no pot available).

    ### Test 4 — Lust detection (PROV-01 MAIN VERIFICATION)
    Best case: be in a group with a Shaman/Mage/Evoker/Hunter who can cast lust. Alternatively self-lust as one of those classes, or join a group-finder run where lust is guaranteed.

    1. Have a tracked "lust" entry in a visible section (drag from Suggested if needed).
    2. Receive lust (Bloodlust / Heroism / Time Warp / Fury of the Aspects / Primal Rage).
    3. Expected: a 40s lust timer starts, icon matches the actual lust spell.
    4. Debug chat should print: `|cff00ccffTBT Debug|r: Lust detected (spellID NNNNN), timer started.`
    5. Report: PASS / FAIL.

    ### Test 5 — No-restart guard (D-12 — NEW verification)
    1. Immediately after Test 4 (lust timer still running, e.g. ~30s remaining), cause a second lust application if possible.
    2. Expected: the timer does NOT reset to 40s. It continues counting down.
    3. Debug chat should NOT print a second "Lust detected" line for the duplicate.
    4. Report: PASS / FAIL / SKIP (if a second lust cannot be triggered).

    ### Test 6 — Lust cancellation (LIFE-02 — NEW verification)
    1. After a lust timer expires naturally (40s elapsed), verify the bar disappears on its own.
    2. If you can dispel/remove the lust buff, verify the timer cancels early.
    3. Look for debug print: `|cff00ccffTBT Debug|r: Cancelled N timer(s): Bloodlust` (or your class's lust) on early cancellation.
    4. Report: PASS / FAIL (natural expiry is sufficient; early cancellation is best-effort).

    ### Test 7 — M+ / secret-aura regression (PITFALL-6 + one-shot log verification)
    1. Enter a Mythic+ dungeon or any context where `C_Secrets.ShouldAurasBeSecret()` returns true.
    2. Debug chat should print once: `|cff00ccffTBT Debug|r: aura scan blocked — ShouldAurasBeSecret() returned true`.
    3. Expected: this message appears AT MOST ONCE per combat/zone session. Spam = regression in the one-shot flag (ns.secretGateLogged).
    4. When lust is used inside the M+, the lust timer should STILL start despite the secret gate — LUST-01 preservation is the load-bearing test.
    5. Exit combat or change zones — you may see `secret-gate log cleared` once on the next entry (debug log).
    6. Report: PASS / FAIL / SKIP.

    ### Test 8 — Preview mode smoke test (PITFALL-4 guard — no regression in preview)
    1. Type `/tbt` to open CDM settings.
    2. Hover the TBT section headers (Bars / Buffs) to trigger preview.
    3. Expected: preview bars/icons appear for all non-hidden tracked buffs. Lust/Heroism in the Suggested section shows the correct class-specific icon (validates ns.GetHunterLustSpell + ns.CLASS_LUST_SPELL namespace reads after the data move).
    4. Trinket and pot preview bars may show 0-second duration — pre-existing bug, NOT a Phase 19 regression. Fix is scheduled for Phase 21 (LIFE-03).
    5. Close CDM. Expected: preview bars disappear cleanly; real active timers (if any) remain.
    6. Report: PASS / FAIL.

    ### Turn off debug logging
    ```
    /tbt debug
    ```

    ### Final summary
    Reply with either:
    - `approved` — if all tests are PASS or SKIP (no FAIL).
    - The 8-test bullet list with specific FAILs noted and any Lua error text pasted verbatim.
