# Phase 57.5 Plan 01: Reminder alternatives saved data and dialog Summary

Schema v11 moves every reminder's "Ends when you cast" list into a new `alternatives` key, mirrored and selftested first in migrate-dryrun.js. The tracker dialog shows reminders an "Also satisfied by (comma separated):" field built from the same spell-ID list row the cast rule uses.

## Decisions (Claude's discretion per CONTEXT)

- **The new saved key is `alternatives`.** It is an array of positive spell IDs and is stored as nil when empty. After v11 a reminder never carries `endOnCast`, and a buff or cooldown never reads `alternatives`.
- **This is the one deliberate divergence from "reminders are buffs"** (RALT-01, user decision 2026-09-29). Every new comment that touches it says so.
- **v11 conversion.** Only kinds in `ns.REMINDER_KINDS` (userReminder and metaReminder) that have a non-nil `endOnCast` are converted:
  - A non-empty table becomes `alternatives` as the SAME table.
  - If an `alternatives` table already exists, each positive numeric ID not already in it is appended.
  - An empty or non-table rule is dropped.
  - `endOnCast` is then cleared.
- **Selftest shape.** Cases I and J now call `migrateV10(db, [])` directly, following case H's precedent. Cases A, D, F and G assert schemaVersion 11. Case K covers v11 on its own (Fixture G). Case L runs the real v9 -> v10 -> v11 chain on Fixture F.
- **Dialog.** Five file-locals sit above TRACKER_FIELDS: `BuildSpellListField`, `SetSpellListText`, `UpdateSpellListIcons`, `ReadSpellList` and `ValidateSpellList`. Both `endOnCast` and the new `alternatives` field use them.
  - `endOnCast` gained `visible = not ns.REMINDER_KINDS[ctx.kind]`.
  - `alternatives` is visible only for reminders.
  - Hidden rows collapse in the walker's Layout, so the two fields share one slot with no gap.

## Lua-to-mirror reconciliation

`ns:MigrateReminderAlternatives` matches `migrateV11` line by line:

| Step | Lua | JS mirror |
|------|-----|-----------|
| Gate | `ver >= CURRENT_SCHEMA_VERSION` (11) / `ver < 10` | `schemaVersion < 10 \|\| schemaVersion >= 11` |
| Which entries | `ns.REMINDER_KINDS[entry.trackerType]` and `entry.endOnCast ~= nil` | `REMINDER_KINDS.has(...)` and `entry.has('endOnCast')` |
| Clear the rule | `entry.endOnCast = nil` | `entry.delete('endOnCast')` |
| Move | same table when `alternatives` is not a table | same Map |
| Merge | numeric > 0, not present (inner numeric loop) | same, via a Set |
| Drop | empty or non-table | same |
| Version | writes 11 | writes 11 |

There is no intentional difference. Lua tests non-empty with `#rule > 0` and JS with `Map.size > 0`. These agree for every array-shaped table SavedVariables writes.
