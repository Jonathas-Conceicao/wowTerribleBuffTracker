<objective>
Rewrite BuffEngine.lua's preview lifecycle to the additive-preview pattern: preview procs live in a separate `ns.previewTimers` table; real procs stay in `ns.activeTimers`. `ns:StartAllPreviewTimers` writes to `ns.previewTimers` (skipping keys with a live real proc) and pulls all display data from `ns:GetDisplayInfoForKey(key)`. `ns:ClearAllTimers` becomes a preview-scoped wipe (no snapshot/restore). `ns:GetActiveTimers` gains a merge with real-priority. Delete the `savedPreviewTimers` local, the `ns.previewActive` flag, and the `if ns.previewActive then return end` guard in `ns:OnUnitAura`. Update CDMTab.lua's 3 `ns.previewActive or ns.configOpen` expressions to `ns.configOpen` (required by D-14 flag deletion; `ns.configOpen` alone carries the same semantics since it is set/cleared in StartPreview/StopPreview).

Purpose: Close LIFE-03. Trinket/pot preview bars will show their real durations (resolved by each provider's GetDisplayInfo in Phase 20) instead of the v0.2.3 0-second sentinel. As a side effect, the pre-existing mid-CDM real-cast-loss bug identified during Phase 20 verification is eliminated — a trinket cast while CDM is open now writes `ns.activeTimers["trinket"]`, wins the merge for key "trinket", and persists after CDM close because `ClearAllTimers` no longer wipes `ns.activeTimers`. PITFALL-4 is retired.

Output: BuffEngine.lua with the new preview shape: separate `ns.previewTimers`, additive `StartAllPreviewTimers`, preview-only `ClearAllTimers`, merging `GetActiveTimers`, and `OnUnitAura` with the preview guard removed. CDMTab.lua with 3 one-word changes (remove `ns.previewActive or`). All other files untouched. CURRENT_SCHEMA_VERSION=3 unchanged.

        -- Phase 21 (D-07/D-08/D-09): additive preview. Writes to ns.previewTimers (never to
        -- ns.activeTimers). Skips keys with a live real proc so real beats preview at insertion

        -- ns:GetAtRestMetaIcon from the caller.
        wipe(ns.previewTimers)
        local now = GetTime()
        for key, entry in pairs(ns.db.trackedBuffs) do
            if entry.section ~= "hidden" then
                -- Skip if a live real proc already owns this key (D-05 priority at insertion time)
                local real = ns.activeTimers[key]
                if not (real and real.expiresAt > now) then
                    local info = ns:GetDisplayInfoForKey(key)
                    if info then
                        ns.previewTimers[key] = {
                            key = key,
                            spellID = info.spellID, -- numeric (D-10); Display tooltip handler uses uniformly
                            icon = info.icon,
                            label = info.label,
                            duration = info.duration,
                            expiresAt = now + info.duration,
                            startedAt = now,
                            section = entry.section,
                            layoutOrder = entry.layoutOrder,
                            -- NO source field, NO lustBuffID, NO castSpellID — preview-only entry

                    end
                end
            end
        end
