    2. **Add `ns:ScanActiveTimersForCancellation()` function (per D-01, D-02, D-03, D-04, D-05):**
       Add the function BEFORE `ns:OnUnitAura` (insert it after `ns:ClearAllTimers` at ~line 210, before the OnUnitAura function). Implementation:

       ```lua
       function ns:ScanActiveTimersForCancellation()
           local cancelledCount = 0
           local cancelledLabels

           for spellID, timer in pairs(ns.activeTimers) do
               if timer.source == "cast" then
                   local aura = C_UnitAuras.GetPlayerAuraBySpellID(spellID)
                   if aura == nil then
                       ns.activeTimers[spellID] = nil
                       cancelledCount = cancelledCount + 1
                       if ns.debugLogging then
                           if not cancelledLabels then
                               cancelledLabels = {}
                           end
                           table.insert(cancelledLabels, timer.label or tostring(spellID))
                       end
                   end
               end
           end

           if cancelledCount > 0 then
               if ns.debugLogging and cancelledLabels then
                   print(
                       "|cff00ccffTBT Debug|r: Cancelled "
                           .. cancelledCount
                           .. " timer(s): "
                           .. table.concat(cancelledLabels, ", ")
                   )
               end
               if ns.UpdateDisplay then
                   ns:UpdateDisplay()
               end
           end
       end
       ```

       Key design points:
       - Zero allocation in non-debug hot path: `cancelledLabels` only created when `ns.debugLogging` is true AND a timer is cancelled
       - `cancelledCount` is a plain integer, no GC pressure
       - `timer.source == "cast"` filter: timers with nil source (preview, future lust) are skipped because `nil ~= "cast"`
       - Single `ns:UpdateDisplay()` call after all removals (D-02)
       - Single summary debug line (D-03), not per-timer
       - No grace period — immediate cancellation when aura is nil (D-05)
       - Removing entries during `pairs` iteration is safe in Lua (established pattern at line 82-88)

    3. **Replace Phase 8 placeholder in OnUnitAura (per D-01):**

