in this phase, so a /reload picks the build up (no full client restart needed). There is no schema

expected: no Lua error; every tracker you own for a spell this character knows still shows exactly as before (see item 3 for the ones that are expected to go grey).

### 1. Load on Advanced

result: pass (user, 2026-09-29, Forever: "the new load rule, the previews and the visibility (in gray) on the cdm window is all functional ... all 3 states")

### 2. Saved value

### 3. EXPECTED after the update, not a bug: trackers for spells you don't know go grey

Setting Load to Always restores each one exactly as before.
result: pass (user, 2026-09-29, Forever: "the new load rule, the previews and the visibility (in gray) on the cdm window is all functional ... all 3 states")
