<objective>
Fix STEAL-14: the Edit Mode preview shows every merged entry, bars included.

Diagnosis (from code; CONTEXT says start from whether the bar viewer's frames are shown while
editing, and whether the bar container publishes merged slots in preview):

- Publishing is not the gap.
  - `ns:RefreshMergeShownSlots` publishes every configured entry while `ns:IsMergePreviewState()`
    (`seen == 0`).
  - `RenderBarContainer` appends them before the example-slot check (`if barEditing and #slots == 0`),
    so the example slot never displaces them.
  - `MergedSlotsFor` returns them.
  - Since Phase 68 CR-01 the flush reaches preview frames.
  - The POC's version of this bug was mostly CR-01: bar frames were only ever placed by the bar
    viewer's rare Layout hook.
- What is still missing is Blizzard's frame itself.
  - TBT moves Blizzard's item frame onto the cell, so the cell shows only what Blizzard shows.
  - In Edit Mode, Blizzard puts the viewers into editing only through
    `EditModeAccountSettingsMixin:RefreshCooldownViewer`, which calls
    `SetIsEditing(showCooldownViewer)`. That depends on Edit Mode's own Cooldown Manager checkbox
    (EditModeManager.lua:2687-2697).
  - When that checkbox is off, `CooldownViewerItemMixin:ShouldBeShown` hides every inactive item
    of a hide-when-inactive viewer. That is Tracked Bars and Tracked Buffs, by default
    (CooldownViewer.lua:284-308).
  - `CooldownViewerMixin:ShouldBeShown` also hides the whole viewer when its Visibility is In
    Combat or Hidden (CooldownViewer.lua:1888-1920).
  - Either way the frame on TBT's cell is hidden, and the merged bar row is empty.
- TBT may not `SetShown` a Blizzard item frame or viewer. That is the OPEN ITEM in
  MergeReanchor.lua and the "no Show, no Hide" rule in MergeMode.lua.
- So, while previewing, TBT draws its OWN placeholder on the cell of any merged slot whose
  Blizzard frame is not visible. It does not attach that slot, so the hidden Blizzard frame goes
  back to the parked viewer. A slot whose frame is visible is untouched and still shows
  Blizzard's own frame.
- The placeholder uses only mirror data that is never secret (spellID, iconOverride, label). It
  reads no aura and relays nothing, so it is not the redraw path Phase 70 deletes. It is the same
  icon-and-name, empty-bar placeholder TBT already draws for its own inactive trackers in Edit Mode.

Output: MergeMode.lua and Display.lua edited.
</objective>
