From Providers.lua (created in Plan 17-01):
```lua
-- Registry (Phase 17: single entry):
ns.providers = { UserSpellProvider }

-- Dispatch entry point:
ns:DispatchEventToProviders(event, ...)
-- Side effect: if any interested provider's OnTrigger returns a proc, assigns
--   ns.activeTimers[proc.key] = proc and calls ns:UpdateDisplay().
-- Returns: number of procs handled (0 if no match).
```

UserSpellProvider:OnTrigger returns an ActiveProc with this exact shape (for numeric-keyed trackedBuffs entries only; string keys like "trinket"/"pot"/"lust" are ignored and return nil):
```lua
{
    key         = spellID,       -- numeric; same as DB key
    icon        = <iconID>,
    duration    = entry.duration,
    label       = entry.label or ("Spell " .. spellID),
    expiresAt   = GetTime() + entry.duration,
    source      = "cast",
    startedAt   = <now>,
    section     = entry.section or "bars",
    layoutOrder = entry.layoutOrder,
    spellID     = spellID,       -- preserved for Display compat during coexistence
}
```
