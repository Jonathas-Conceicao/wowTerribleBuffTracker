<objective>
Stop TBT reaching into Blizzard's Edit Mode when a TBT container is selected (backlog 999.9,
EDM-08). `ns:SelectContainer` in `EditModeFrames.lua` loses its
`pcall(EditModeManagerFrame.ClearSelectedSystem, EditModeManagerFrame)` block. Nothing replaces it.

Purpose: a Blizzard Edit Mode mixin method invoked from TBT's click handler taints
`EditModeManagerFrame` by the same mechanism PROJECT.md records for CDM mixins. `pcall` catches
errors, not taint, so the guard never helped. This fix has to land before Phase 63 puts secure
frames next to Edit Mode.
Output: one edited function, one explanatory comment, a scan of every other Edit Mode reference
in TBT recorded in the SUMMARY, and a deployed build.
</objective>
