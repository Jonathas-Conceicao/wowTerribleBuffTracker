## Spacing Scale

WoW UI uses explicit pixel offsets rather than a token scale. The values below
are the specific offsets used by `CooldownViewerSettings` internals — TBT must
match them exactly to feel native.

| Token | Value | Usage |
|-------|-------|-------|
| tab-gap | 3px (y=-3) | Vertical gap between stacked CDM tab buttons (match AurasTab → TBTSettingsTab anchor) |
| panel-inset-top | 72px (y=-72) | TOPLEFT Y offset for content panel from CooldownViewerSettings TOPLEFT — matches CooldownScroll |
| panel-inset-left | 17px (x=17) | TOPLEFT X offset for content panel — matches CooldownScroll |
| panel-inset-right | 30px (x=-30) | BOTTOMRIGHT X offset for content panel — matches CooldownScroll |
| panel-inset-bottom | 29px (y=29) | BOTTOMRIGHT Y offset for content panel — matches CooldownScroll |
| scroll-bar-margin | 17px | Right margin between scroll child width and panel width (space for scrollbar) |

Exceptions: none. All offsets are derived from `CooldownViewerSettings.xml:201-220`
(CooldownScroll anchors). TBT must not introduce new offset values in this phase.

**Source:** Pattern 4 from RESEARCH.md (verified from Blizzard UI source).

## Color

WoW addons use atlas textures and Blizzard backdrop colors — not hex values.
The following are the exact visual treatments for each surface.

| Role | Treatment | Usage |
|------|-----------|-------|
| Tab button background (inactive) | Atlas `questlog-tab-side` (via `LargeSideTabButtonTemplate`) | Unselected TBT tab — matches CDM SpellsTab and AurasTab |
| Tab button background (selected) | `SelectedTexture` shown via `SetChecked(true)` | TBT tab when active — identical behavior to built-in CDM tabs |
| Tab icon (active) | Atlas `hud-buff` via `activeAtlas` KeyValue | TBT tab icon in checked state |
| Tab icon (inactive) | Atlas `hud-buff` via `inactiveAtlas` KeyValue | TBT tab icon in unchecked state (same atlas; CDM dims via alpha or tint automatically) |
| Content panel background | `BackdropTemplate` with `bgFile = "Interface\\DialogFrame\\UI-DialogBox-Background"` | TBT panel surface — same backdrop as ConfigUI was using; matches CDM's inset style |
| Content panel border | `edgeFile = "Interface\\DialogFrame\\UI-DialogBox-Border"`, edgeSize=16, tileSize=32 | Matches CDM category frame border treatment |
| Panel backdrop color | `SetBackdropColor(0, 0, 0, 0.9)` | Same value used in old ConfigUI.lua — visually consistent with Blizzard dialog boxes |

**Accent reserved for:** Nothing in Phase 3. The shell adds no interactive elements
beyond the tab button itself. All accent/highlight states (drop zone highlight,
selected buff) are Phase 4 and Phase 5 concerns.

**Source:** D-01, D-02, D-07 from CONTEXT.md; ConfigUI.lua line 25-33 (backdrop values);
RESEARCH.md Pattern 4 (panel geometry); `LargeSideTabButtonTemplate` from
`CooldownViewer.xml` (tab visual behavior).

## Interaction Contract

### Tab Button Behavior

| Interaction | Expected Result |
|-------------|----------------|
| User clicks TBT tab | TBT panel shows; CooldownScroll hides; TBT tab SetChecked(true); all other TabButtons SetChecked(false) |
| User clicks any CDM tab (Spells/Auras) | hooksecurefunc on SetDisplayMode fires; TBT panel hides; CooldownScroll shows; TBT tab SetChecked(false) |
| User hovers TBT tab | Tooltip shows "TBT Buffs" (wired automatically by LargeSideTabButtonTemplate) |
| CDM settings window opens fresh | Default CDM tab (Spells) is selected; TBT panel is hidden; TBT tab is unchecked |
| CDM settings window opens while TBT tab was last selected | OnShow triggers SetDisplayMode("spells") which fires hook; TBT panel hides; then /tbt re-selects if triggered via slash command |

### /tbt Slash Command Behavior

| State | Action |
|-------|--------|
| CDM settings not visible | Call CooldownViewerSettings:ShowUIPanel(), then call ns:SelectTBTTab() |
| CDM settings visible on a CDM tab | Call ns:SelectTBTTab() directly (no ShowUIPanel needed) |
| CDM settings visible on TBT tab | Call ns:SelectTBTTab() (idempotent — no visible change) |

**Never toggle closed.** /tbt is open-only per D-09.

**Timing note:** ShowUIPanel is synchronous. SetDisplayMode("spells") fires during OnShow
(first open only) and triggers the hooksecurefunc which hides TBT panel.
ns:SelectTBTTab() must be called after ShowUIPanel returns to win the final state.
Both calls happen in the same Lua frame before the game renders — the result is
TBT tab selected regardless of the OnShow sequence.

**Source:** D-09, D-10 from CONTEXT.md; RESEARCH.md Pattern 5 (timing analysis).

### Initialization Gate

All CDM interaction is gated behind EventUtil.ContinueAfterAllEvents for:
- VARIABLES_LOADED
- PLAYER_ENTERING_WORLD
- COOLDOWN_VIEWER_DATA_LOADED

No CDM frame access before this gate fires. This mirrors CDM's own initialization
pattern exactly.

**Source:** RESEARCH.md Pattern 6.
