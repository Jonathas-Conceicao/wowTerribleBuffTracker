# Phase 31 — Plan 01: Single TOC

**Created:** 2026-09-20
**Requirements:** TOC-06, TOC-07, TOC-08, TOC-09

## Approach

Straight migration, no gate. Rewrite the surviving TOC's `## Interface:` line to the comma form, delete
the Camelot TOC and the drift guard that existed only to keep the two aligned, then chase every
reference to the retired files so nothing dangles.

Rollback is one `git revert` plus one `install.bat` run, which is why this is not staged behind a
verification step.

## Tasks

1. **`TerribleBuffTracker_Mainline.toc`** — `## Interface: 120100, 16001`; widen `## Notes:` to name both
   clients. No `## AllowLoadGameType:` line, matching Platynator.
2. **Delete `TerribleBuffTracker_Camelot.toc`** via `git rm` so the case-sensitive name is removed from
   the index, not just the working tree.
3. **Delete `scripts/check-toc.ps1`** — it asserts a two-TOC invariant that no longer exists.
4. **`scripts/release.bat`** — drop the `check-toc.ps1` invocation. Leaving it in would abort every
   release on a missing file.
5. **`scripts/install.bat`** — remove `TerribleBuffTracker_Camelot.toc` from `FILES`. The script
   validates every entry exists before copying, so a stale entry is a hard failure, not a silent skip.
6. **`.gitattributes`** — `.pkgmeta-*` → `.pkgmeta`.
7. **`CLAUDE.md`** — replace the two-TOC constraint and the `check-toc.ps1` / `.pkgmeta-*` architecture
   lines. Keep the `Blizzard_CooldownViewer.toc` reference to `AllowLoadGameType`, which is about
   Blizzard's own TOCs and is still accurate.
8. **Deployed folders** — remove the orphaned `TerribleBuffTracker_Camelot.toc` from every client that
   held one, then run `install.bat`.
9. **Verify** — `git ls-files` shows one TOC; a repo-wide grep for `camelot` / `check-toc` / `pkgmeta-`
   returns nothing outside git history, `CHANGELOG.md`, `.planning/` and `tools/`.

## Verification

- `git ls-files | grep -i toc` → `TerribleBuffTracker_Mainline.toc` and `tools/TBTProbe/TBTProbe.toc` only.
- `_classic_beta_\Interface\AddOns\TerribleBuffTracker\` holds exactly one TOC, reading
  `## Interface: 120100, 16001`.
- **In-game, Forever (human):** TBT is enabled in the character-select AddOns list, loads, `/tbt` opens
  the CDM tab, and bars/icons/Edit Mode work.

## Risks

- **If Forever rejects the comma form, TBT does not load there at all.** Accepted: Platynator ships this
  exact shape on Forever, and the TBTProbe TOC loaded on both clients with it. Recovery is
  `git revert` + `install.bat`.
- `.pkgmeta` handling belongs to Phase 32; the `git mv` of `.pkgmeta-mainline` happens here only because
  `.gitattributes` and the `CLAUDE.md` architecture list reference it in the same edit pass.
