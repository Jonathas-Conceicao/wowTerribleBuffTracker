## Phase 79: Buff Countdown Display Fix

**Goal:** A running buff timer's icon shows its remaining time the way the game's buff display does.
**Requirements:** BUFFTIME-01, BUFFTIME-02, BUFFTIME-03, VER-14
**Plans:** 1 — `79-01` (`cbc4008`, review notes `bde1da4`)

**Cause:** TBT's buff icons used the cooldown countdown format, which rounds hours up. Blizzard's CDM
buff icons switch to the aura format with `SetUseAuraDisplayTime(true)`
(`CooldownViewer.lua:1397`, and per state at :877/:895 vs :924, applied at :1150).

**Fix:** `ApplyCountdownFormat(icon, auraTime)` in `Display.lua`. It sets the aura format for every
timer-branch icon (buff, reminder, Trinket/Pot, a cooldown's buff) and the cooldown format in
`ApplyCooldownSlot`. It is stamped, guarded on the method, and redraws the sweep when the format
changes.

**Success criteria:**
1. A buff with about 1h left matches the game's buff display, never "2h". Passed, in game.
2. Real cooldowns keep their format, and pooled icons switch correctly. Passed, by code trace.
3. Timers, sweep, aura look and bars are unchanged, with no error on a client without the method.
   Passed.
4. The user confirmed in game before the release. Passed.

**Noted:**
- One `/reload` showed the flask with no timer until a relog. It did not reproduce, and Lua errors
  were off at the time; the user called it a fluke.
- The "6m shows 2h" case was not reproduced.
