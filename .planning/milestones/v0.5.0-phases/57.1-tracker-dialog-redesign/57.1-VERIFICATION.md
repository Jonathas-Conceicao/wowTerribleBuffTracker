# Phase 57.1: Tracker Dialog Redesign Verification Report

**Phase Goal:** The add/edit dialog presents its two modes as two tabs made from Blizzard's own templates. Every Advanced field is prefilled with its default, so nothing expands and every choice reads clearly. The tabs are named "General" and "Advanced" by user decision on 2026-09-28, superseding "Simple"/"Detailed". That decision also settled that there is no Reset button and that the migration drops `detailed`, clearing the Advanced keys on records that were not detailed.
