`fields` / `fieldKeys` contract (consumed by 54-02's shared field definition, EDIT-03): `fields` is a
table keyed by saved-entry field name. `fieldKeys` is the array of every entry field name the
dialog owns. A file-local `ENGINE_OWNED` set lists the names the engine writes itself and never
copies from `fields`: `spellID`, `duration`, `label`, `trackerType`, `section`, `layoutOrder`,
`key`, `itemID`, `iconOverride`. Add copies every non-engine-owned `fields` pair onto the new entry.
Update assigns `entry[k] = fields[k]` for every non-engine-owned `k` in `fieldKeys`, so a nil value
CLEARS the field (that is how an unticked "cover all ranks" is stored as nothing, never false).
A field added later to the dialog definition is therefore persisted by both functions with no
edit here.
