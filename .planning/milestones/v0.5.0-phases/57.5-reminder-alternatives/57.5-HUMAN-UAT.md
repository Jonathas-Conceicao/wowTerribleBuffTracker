## Tests

**Setup**
- Run everything on the Forever beta on a paladin, except items 14 and 19, which are on Midnight retail.
- Turn on `/console scriptErrors 1`.
- The TOC did not change, so a /reload picks the build up. The schema v11 migration runs on that
  /reload.
- SavedVariables are account-wide. Items marked **logout** need a REAL logout/login, because
  SavedVariables are only written on logout.
- "Aura spell ID:" is the line TBT's ID tooltip adds to a hovered buff on your buff bar.
- To place a blessing tile, open the Reminders tab and drag the tile from the Suggested section
  into Buff Reminders.

### 0. First load of this build
expected: /reload gives no Lua error. Every existing tracker is unchanged. `/dump TerribleBuffTrackerDB.schemaVersion` prints 11.
result: pass (user, 2026-09-29: "Everything looking good on all mage, pally and lock")

### 1. v11 migration (logout)
expected:
- **Setup,** only if none of your user reminders saved under v10 has an "Ends when you cast" list:
  - Pick one of your user reminders, then run `/run local e = TerribleBuffTrackerDB.trackedBuffs["userReminder:<id>"] e.endOnCast = { <otherID> } e.alternatives = nil TerribleBuffTrackerDB.schemaVersion = 10`.
  - Also give one buff tracker an "Ends when you cast" list in its dialog.
- Log out fully and log back in.
- Editing the reminder shows <otherID> in "Also satisfied by (comma separated):", with its icon.
- `/dump TerribleBuffTrackerDB.trackedBuffs["userReminder:<id>"]` shows `alternatives` and no `endOnCast`.
- The buff tracker still has its endOnCast list.
- schemaVersion is 11.
result: pass (user, 2026-09-29: "Migration worked")
