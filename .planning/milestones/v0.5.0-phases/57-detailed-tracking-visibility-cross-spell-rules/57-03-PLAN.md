Interfaces from Plan 02 (BuffEngine.lua; call them, do not re-derive them):
- `ns:VisibilityGate(key, entry)` -> nil | true | false. nil = no gating (simple tracker, "always", non-user kind, nil entry, or unknown state) -- behave exactly as today. true = the condition holds: the slot must draw even under hideWhenInactive (for "absent" this is the reminder). false = the condition fails: the slot must not draw, UNLESS `ns.configOpen` or the container is in Edit Mode. Allocation-free, reads only a cache.
- `ns:VisibilityShowsIn(containerKey)` -> boolean: some gated tracker filed in that container returns true from the gate. Loops `ns.visibilityKeys` numerically, allocation-free.
- `ns.visibilityKeys`: array of gated keys, replaced per rebuild; read-only here.

Facts from Display.lua at 0459903:
- `local function SlotDraws(entry, timer, settings, iconEditing, engineDrawsHere)` (~line 86): first returns `entry.cdmShown == true` for an engine-drawn merged slot, then returns `timer ~= nil or ns:IsCooldownSlotEntry(entry) or entry.isMerged or not settings.hideWhenInactive or ns.configOpen or iconEditing`. Its comment says it mirrors RenderIconContainer's branch chain exactly, in the same order.
- `RenderIconContainer(def, container, settings, timers, now)` (~2228): `local hasActiveIcons = #timers > 0 or (cooldownSlotCounts[def.key] or 0) > 0 or mergedCount > 0 or engineDrawsHere`; then `iconEditing = ns.editModeActive`; slots are DB entries (with `entry.key` set) plus mirrored merged slots (no `detailed`). In the per-slot loop (`for slotIndex, entry in ipairs(slots)`), `local timer = activeByKey[entry.key]`; the branch chain is: `if engineDrawsHere and entry.isMerged then` ... `elseif timer then` ... `elseif ns:IsCooldownSlotEntry(entry) then` ... `elseif entry.isMerged or not settings.hideWhenInactive or ns.configOpen or iconEditing then` (the placeholder branch: ClearCooldownStamps, ApplyCachedIcon, ClearIconDesaturation, clears the sweep via `icon.cooldown:Clear()` -- i.e. a full-colour icon with no sweep and no timer, exactly the "absent" reminder look) ... `else icon:Hide() end`.
- `RenderBarContainer(def, container, settings, timers, now)` (~1956): `local hasActiveTimers = #timers > 0 or mergedCount > 0`; `barEditing = ns.editModeActive`; after `BuildActiveByKey(timers)`, `local showPlaceholders = not settings.hideWhenInactive or ns.configOpen or barEditing`; when true it walks `pairs(ns.db.trackedBuffs)` and inserts entries with `entry.section == def.key and not ns:IsCooldownSlotEntry(entry) and ns:IsRacialKeyVisible(dbKey)` (setting `entry.key = dbKey`), then sorts; otherwise it inserts every timer from `timers`. A slot with no timer draws the placeholder bar ("empty bar, no fill, no timer") -- the bar reminder look, per 57-CONTEXT (Claude's discretion: reuse the existing placeholder bar unchanged).
- Display redraws at 20 Hz from an OnUpdate tick; these functions must construct no table.

Design choices recorded here:
- The predicate value is held in a local named `gate` in each render loop, so the four uses read the same way.
- Hide branch placement: directly after the engine-drawn merged branch, before `elseif timer then`, so a gated-off tracker is hidden even with a running timer or as a cooldown slot. SlotDraws gets the same test in the same position (after its merged early return), keeping its "mirrors the chain in the same order" contract.
- The "absent" reminder on icons is the existing placeholder branch, reached through an added `gate == true` term in its condition.

Hazards: CRLF -- Edit tool only, never `sed -i` or a redirect; bare `stylua Display.lua`; comments on their own line above a statement, never inside a multi-line condition (stylua CRCRLF). stylua will re-wrap the longer conditions at 120 columns; that is expected. Do not write the word OnUpdate in any new line (the whole-phase gate counts it). No new `{` in SlotDraws, RenderIconContainer or RenderBarContainer (gated against 0459903). Stage only Display.lua by explicit path; never `.gitignore`; no scratch files in the repo.
