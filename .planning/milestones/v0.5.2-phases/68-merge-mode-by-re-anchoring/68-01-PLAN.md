<objective>
Turn `MergeReanchor.lua` from an opt-in prototype into Merge Mode's real placement engine: active
whenever Merge Mode is on, styled by every TBT container setting it can reach through plain C widget
setters, re-placed only when something actually changed, and fully reversible when Merge Mode is
turned off.

Purpose: STEAL-10 (Blizzard draws the merged slot, at TBT's size and style), STEAL-12 (C setters
only), STEAL-16 (TBT's settings, not the CDM's, decide size), STEAL-17 (no per-tick re-placement),
STEAL-18 (clean return on Merge Mode off). Implements the locked Activation, hard-boundary, Styling
(user decision 2026-10-10), Placement-model and STEAL-18 decisions in 68-CONTEXT.md.

Output: reworked `MergeReanchor.lua` with a new public signature
`ns:AttachMergedItem(entry, cell, settings, kind)` (kind is "icon" or "bar") and a new
`ns:MarkMergedPlacementDirty()`. Plan 68-02 rewires Display.lua and MergeMode.lua to them. The file
keeps its name (D: no TOC change, no full client restart).
</objective>
