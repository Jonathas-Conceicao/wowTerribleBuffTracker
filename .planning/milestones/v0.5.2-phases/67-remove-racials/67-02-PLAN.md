<objective>
Remove the racial Suggested offer (RACE-11) and the racial-only display paths (RACE-12): the racial
buff and cooldown tiles on the Buffs and Cooldowns tabs, the CDMTab racial key-shape handling, the
Providers.lua offer API behind them, and Display.lua's live-timer stack count (`timer.stacks`, bar and
icon) and indefinite-timer branch, both of which only racial procs ever produced. Per CONTEXT "What is
removed from code".

Output: CDMTab.lua, Providers.lua (offer half only) and Display.lua with no racial code.

Consumer-before-producer order: this plan removes the Suggested callers together with the API they call,
and only the READERS of proc.stacks / proc.indefinite. The racial provider that still writes those
fields is removed in Plan 04, so nothing calls a deleted function at any point.
