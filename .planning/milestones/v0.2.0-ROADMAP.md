## Key Accomplishments

1. **CDM-integrated config**: TBT tab inside CDM settings with 4 collapsible sections, replacing standalone ConfigUI.lua
2. **Edit Mode containers**: Independent movable bars/buffs containers with position persistence
3. **Drag-and-drop**: Section-to-section drag with CDM-style reorder marker + within-section reordering
4. **Per-container settings**: Full CDM-like settings popup in Edit Mode (orientation, scale, padding, opacity, visibility, bar width)
5. **Taint-free design**: No parentArray, no SetDisplayMode calls, no HookScript on CDM frames
6. **Copy CDM Config**: One-click import of Blizzard CDM settings into TBT

## Key Decisions

| Decision | Rationale |
|----------|-----------|
| LargeSideTabButtonTemplate (not CooldownViewerSettingsTabTemplate) | parentArray causes CDM taint |
| Floating checkbox panel (Plumber pattern) | BasicOptionsContainer not accessible in Midnight |
| OnUpdate watcher (not HookScript on CDM) | HookScript propagates taint in instances |
| Fractional layoutOrder for reorder precision | Integer insertion was unreliable |
| Per-container DB settings | Users want independent bar/buff configuration |
