# Requirements: TerribleBuffTracker

**Defined:** 2026-04-12
**Core Value:** Players can see countdown timers for buffs/cooldowns that the game no longer surfaces automatically.

## v0.2.3 Requirements

Requirements for Trinket & Pot Meta-Trackers milestone. Each maps to roadmap phases.

### Data

- [x] **DATA-01**: Trinket spell table defines 9 entries with spellID, itemID, and duration from trinket_info.csv
- [x] **DATA-02**: Pot spell table defines 4 entries with spellID, itemID, and duration from pots_info.csv
- [x] **DATA-03**: N/A for v0.2.3 — no schema migration needed. v0.2.3 is the first release introducing trinket/pot meta-trackers, so no stale `"trinket"` / `"pot"` keys can exist in pre-upgrade SavedVariables. Superseded by CONTEXT.md D-05 (no schema version bump). Covered by documentation comment in InitBuffEngine.

### Timer

- [x] **TMR-01**: When user casts a tracked trinket spell, a timer starts with that spell's duration
- [x] **TMR-02**: When user casts a tracked pot spell, a timer starts with that spell's duration
- [x] **TMR-03**: If a timer is already active for the same meta-slot (trinket or pot), new cast replaces it (remove old spellID timer, create new one)
- [x] **TMR-04**: Timer is keyed by actual spellID so existing aura scan cancellation works (clear timer when buff drops, if auras are visible)

### Icons

- [x] **ICON-01**: At-rest CDM icon shows the first matching equipped trinket (slots 13/14) or fallback to first list entry
- [x] **ICON-02**: At-rest CDM icon for pot shows the first matching consumable found in bags or fallback to first list entry
- [ ] **ICON-03**: When timer is active, icon switches to the cast spell's icon (both CDM and display)
- [ ] **ICON-04**: When timer expires, icon reverts to the resolved at-rest icon
- [x] **ICON-05**: At-rest icon refreshes when CDM settings window opens (out of combat)
- [x] **ICON-06**: N/A for v0.2.3 — refresh is piggy-backed on the CDM settings open path (StartPreview, ICON-05) instead of equipment/bag events. Player only sees the CDM preview when settings open, so refreshing on every equipment/bag change is wasted work. Superseded by CONTEXT.md D-03/D-04. Covered by an inline comment in ns:RefreshMetaIcons.
- [x] **ICON-07**: All inventory/bag scanning gated on not InCombatLockdown(); fallback icon used if scan unavailable

### CDM Integration

- [x] **CDM-01**: Trinket and pot entries appear in Suggested section alongside lust
- [x] **CDM-02**: Trinket and pot entries support copy-on-drag to Bars/Buffs sections (existing Suggested behavior)

## Future Requirements

### Icon Polish

- **ICON-08**: Async icon retry via GET_ITEM_INFO_RECEIVED for uncached items (deferred — fallback icon sufficient for now)

### Aura Enhancements

- **AURA-F01**: Update timer durations from aura data (not just cancellation)
- **AURA-F02**: Aura-based buff auto-discovery for untracked buffs

## Out of Scope

| Feature | Reason |
|---------|--------|
| Async icon retry (GET_ITEM_INFO_RECEIVED) | Fallback icon sufficient; revisit if usability is poor |
| Aura-based auto-discovery of new trinket/pot spells | Only track user-provided spell lists |
| Passive trinket proc detection | All tracked trinkets are on-use; cast detection only |
| Aura-based timer duration updates | Secret values block reading expirationTime in combat |
