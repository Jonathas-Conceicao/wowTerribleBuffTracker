<objective>
Land Success Criterion 3 — the `ApplyDispelBorder` dirty check deferred from Phase 48.1 — and land it
FIRST, so Phases 51 and 52 (two full in-game review passes) verify it for free and it needs no gate of
its own (CONTEXT.md D-03).

Today the function collapses a secret atlas to the `SECRET_ATLAS_KEY` sentinel and then deliberately
re-sets on every pass (`or key == SECRET_ATLAS_KEY`), because no secret may be compared against a
stored value. The fix is a SECOND stamp holding a NON-SECRET identity — the entry's `cooldownID`
(D-04) — so the pass can ask "is this the same entry as last time?" without ever touching the atlas.

Purpose: remove a per-pass C call for every bordered widget, in the safest possible window.
Output: `Display.lua`'s `ApplyDispelBorder` keyed on identity, its four call sites consistent, and the
pandemic FX split confirmed as justified divergence rather than duplication.

**This plan ships NO visible behaviour change.** If anything about the border renders differently, the
change is wrong.
</objective>

   `identity` into a local `id`, and if `issecretvalue(id)` is true set `id = nil`. `issecretvalue()`
   comes BEFORE any comparison — the standing project rule — and a secret identity therefore never

   false)` when `widget._dispelKey ~= key` (unchanged), OR when `widget._dispelID ~= id` (the widget is
   now showing a different entry), OR when `id == nil` (no readable identity this pass, so the skip
   cannot be proven safe and the old behaviour is kept). Stamp BOTH `widget._dispelKey = key` and
   `widget._dispelID = id` inside that branch. `key` keeps its existing definition —
   `issecretvalue(atlas) and SECRET_ATLAS_KEY or atlas` — unchanged; `SECRET_ATLAS_KEY` itself stays.

3. **Clear the new stamp where the old one is cleared.** In the `if not shown then` branch, inside the
   existing `if widget._dispelShown then` block, set `widget._dispelID = nil` on the line after
