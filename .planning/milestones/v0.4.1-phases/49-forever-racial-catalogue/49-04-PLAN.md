<objective>
Give the three state-shaped racials a lifecycle the existing engine cannot express today: a buff
tile that shows as simply **on**, with no countdown, until something takes it down.

Purpose: success criteria 6, 7 and 8 of ROADMAP §49, and the only part of this phase with **no
analog anywhere in the codebase** — 49-PATTERNS.md § "No Analog Found" confirms every render path
unconditionally computes a countdown from `timer.expiresAt` / `timer.duration`, and there is no
branch for "this proc has no meaningful duration, draw it as on". That is designed here, not copied.

Output: an indefinite proc shape with render support on both paths, an aura-driven start, an
aura-loss and combat-enter teardown, and the Skyborne upward duration correction.

Locked decisions implemented here:

| ID | Decision |
|----|----------|
| D-1 | Shadowmeld: aura-cancelled via an `aliveBuffs` assignment, **plus** an instant clear on entering combat, because aura reads are secret in combat for a tainted caller |
| D-2 | Plainsrunning: same shape as Shadowmeld, but it has **no cast**, so its proc starts from `UNIT_AURA` |
| D-3 | Skyborne: always start on the **short** duration; out of combat, read the aura's real duration and correct **upward**. A racial that under-runs is recoverable; one hanging 14 minutes past its buff is not |
| D-6 | Find Treasure and Shadowmeld both get an indefinite buff tile; only Shadowmeld gets a cooldown tile, because only Shadowmeld has a cooldown |

Claude's discretion exercised, per 49-CONTEXT.md ("How an indefinite tile is represented
internally: sentinel expiry, a flag, or a separate path"): **both** of the two shapes
49-PATTERNS.md named, deliberately. A `proc.indefinite = true` flag is the thing every render path
branches on, **and** a large backstop `duration` / `expiresAt` is written so that any code path
that does arithmetic on those fields without knowing about the flag still produces a sane number
rather than a nil-arithmetic raise or a negative remaining. Belt and braces, because this proc
shape now reaches five files.
</objective>
