# Requirements: TerribleBuffTracker

**Defined:** 2026-03-28
**Core Value:** Players can see countdown timers for buffs/cooldowns that the game no longer surfaces automatically.

## v0.2.0 Requirements

Requirements for Config & Edit Mode Rework. Each maps to roadmap phases.

### Migration

- [x] **MIG-01**: User's existing tracked buffs are preserved when upgrading to v0.2.0
- [x] **MIG-02**: Existing displayMode/enabled values are mapped to section field (bars/buffs/hidden)

### CDM Tab

- [x] **TAB-01**: User sees a "TBT Buffs" lateral tab button in CDM settings window
- [x] **TAB-02**: User sees a TBT content panel when clicking the TBT tab
- [x] **TAB-03**: User sees 4 sections: Tracked Buffs, Tracked Bars, Not Displayed, Suggested
- [x] **TAB-04**: User can add a new buff via Add button in Suggested (prompts Spell ID + Duration)
- [x] **TAB-05**: Newly added buffs appear in Not Displayed section
- [x] **TAB-06**: User can drag a buff onto the delete drop zone in Not Displayed to remove it
- [x] **TAB-07**: Old standalone config UI is removed; /tbt opens CDM settings to TBT tab

### Drag-and-Drop

- [x] **DND-01**: User can drag a buff from one section to another to change its display mode
- [x] **DND-02**: User sees a ghost frame following cursor during drag
- [x] **DND-03**: User sees drop zone highlighting when dragging over valid targets

### Edit Mode

- [x] **EDM-01**: User sees two independent movable elements (bars container, buffs container) in Edit Mode
- [x] **EDM-02**: User can toggle bar/buff container visibility via Edit Mode sidebar checkboxes
- [x] **EDM-03**: Fresh install copies CDM position/scale settings once as initial values
- [x] **EDM-04**: After initial copy, TBT position/scale is set exclusively via Edit Mode
- [x] **EDM-05**: Display does not re-anchor to CDM when CDM layout refreshes

## Future Requirements

### Suggested Buffs

- **SUG-01**: Suggested section shows class/spec-appropriate buff suggestions
- **SUG-02**: Suggestions update when player changes spec

## Out of Scope

| Feature | Reason |
|---------|--------|
| Buff tracking engine changes | Not in this milestone — engine works correctly |
| Timer display rendering changes | Not in this milestone — visual style is settled |
| Real buff suggestions | Placeholder only; requires class/spec data research |
| Standalone config window | Being replaced by CDM tab |
