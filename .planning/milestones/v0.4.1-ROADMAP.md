### Phase 46: Item Catalogue & Suggested Tiles
**Goal**: Opening the Cooldown Manager on either flavour scans the player's bags and offers every
untracked consumable in Suggested, each showing the item's own icon and current count.
**Depends on**: Nothing (first phase of the milestone)
**Requirements**: ITEM-01, ITEM-03, ITEM-08, ITEM-10
**Success Criteria** (what must be TRUE):
  1. Opening the CDM produces a consumables catalogue built from the player's bags, keyed by itemID
     rather than by bag and slot
  2. Every catalogued item appears in the Cooldowns tab's Suggested section, showing the item's own
     icon and the number currently held
  3. Quest items, recipes, keys, trade goods and bandages never appear in the catalogue
  4. The catalogue and its Suggested tiles appear identically on both Midnight retail and the WoW
     Forever beta

### Phase 47: Item Tracking & Cooldown Sharing
**Goal**: Dragging a Suggested item creates a real cooldown tracker whose count and shared-cooldown
display stay correct through use, looting, and combat.
**Depends on**: Phase 46
**Requirements**: ITEM-02, ITEM-04, ITEM-05, ITEM-06, ITEM-07, ITEM-09
**Success Criteria** (what must be TRUE):
  1. Dragging a Suggested item tile into a container creates an ordinary cooldown tracker for that
     item, and the item drops out of Suggested once tracked
  2. Using any item refreshes the displayed cooldown of every tracked item that shares its cooldown
  3. A tracked item's count decreases only when a use actually lands, never when a press is refused
  4. Leaving combat reconciles a tracked item's displayed count against the bags
  5. A tracked item keeps its tile and running cooldown after its stack reaches zero and the item
     leaves the player's bags
**Plans**: 3 plans (47-01 through 47-03)

## Milestone Summary

### What shipped

Four features, in the order they were built:

1. **Generic item tracking** (ITEM-01..10) — a bag-derived consumables catalogue keyed by itemID,
   drag-to-track, shared-cooldown display, use-driven counts, out-of-combat reconciliation.
2. **The pandemic highlight** (PAND-01..05) — Blizzard's refresh-window indicator mirrored onto
   TBT's own icons and bars for merged entries.
3. **The dispel-type border** (DISP-01..04) — inserted mid-milestone as Phase 48.1 on user request,
   following the Phase 27.1 precedent rather than renumbering.
4. **The Forever racial catalogue** (RACE-07/08/10) — all ten races, 21 racials, each its own
   race-gated tracker entry, replacing the two generic `racial`/`racial2` slots.

### Key decisions

- **Spell categories are not used for items.** A per-item `C_Item.GetItemCooldown(itemID)` read
  already reflects a shared cooldown, so tracking items individually gets cooldown sharing for free.
  Confirmed in game: one health potion fired the cooldown on all three potions sharing it.
- **Blizzard computes, TBT mirrors.** Both the pandemic highlight and the dispel border read
  Blizzard's own computed state rather than recomputing it. Recomputing is closed by the platform in
  both cases: the inputs are secret and the APIs that would redo the math key off `auraInstanceID`,
  which is flagged `DisallowTaintedAccess`.
- **RACE-10 replaced the two-slot racial model** with one entry per racial, visible only to its own
  race, migrated from the old keys. RACE-09 was closed as obsolete rather than implemented — the
  generic tile its "not yet supported" message lived on stopped existing.
- **Aura-loss cancellation is universal for racials, not opt-in.** A per-row `cancelOnAuraLoss` flag
  existed briefly and was removed: making "does this end when its buff ends" something someone had
  to remember meant each racial that could end early arrived as its own bug report.

### Findings worth carrying forward

- **A secret's visibility and its content have different secrecy.** `border:IsShown()` stays a plain
  boolean while `GetAtlas()` returns a secret string in combat. That asymmetry is what made
  in-combat dispel borders possible at all: *whether* to draw is readable, *what* to draw is not,
  and the atlas is relayed to `SetAtlas` unread.
- **`stylua` writes CRCRLF for a comment inside a multi-line expression**, turning a Lua file binary
  to git. Invisible to `file`, `grep` and `git diff`; only `git ls-files --eol` catches it. Hit in
  Phase 48.1 and again by the Phase 50 planner (via `awk`, on a `.md` file).
- **A confident comment is not a verified fact.** `StartRacialProc` asserted that a racial's
  cooldown tile reads the live game handle. It does not — `ApplyUserCooldown` owns any tracker
  carrying a duration. The first investigation of the Shadowmeld cooldown bug repeated the comment's
  claim and closed the bug as cosmetic.
- **A passing gate proves the path it walks, not the feature.** ITEM-07's gate exercised
  drift-then-correct and passed; the empty-at-login entry point was never walked, and item counts
  were blank after every reload until a user noticed.
