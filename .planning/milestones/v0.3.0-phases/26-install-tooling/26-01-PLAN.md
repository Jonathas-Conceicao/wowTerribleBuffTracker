First, gate on the Phase 25 prerequisite: confirm both `TerribleBuffTracker_Mainline.toc` and `TerribleBuffTracker_Camelot.toc` are tracked at repo root using `git ls-files` (not a directory listing — NTFS is case-insensitive and the capital C in `_Camelot` is load-bearing, Phase 25 D-04). Replace the entire body of `scripts/install.bat`. Keep the repo's batch idiom from `release.bat`: `@echo off`, `setlocal enabledelayedexpansion`, and `if errorlevel 1 (echo ERROR: ... & exit /b 1)` for failure.

Structure, in order:

1. `SOURCE` keeps the existing `%~dp0..\` derivation (single trailing backslash; drop the current file's stray doubled one).
2. Root resolution (D-01): set `WOW_ROOT` to `%ProgramFiles(x86)%\World of Warcraft` on its own top-level line, then on the next line a **single-line** `if defined TBT_WOW_ROOT set "WOW_ROOT=%TBT_WOW_ROOT%"`. Do NOT wrap this in a parenthesized `if/else` block — `%ProgramFiles(x86)%` contains literal parentheses and breaks block parsing; keeping both assignments outside any block and quoting the whole `set` argument avoids it entirely.
3. Define `FILES` once as a space-separated list of the 10 entries in `<constants>` (D-08/D-09/D-10). Define `FLAVORS` once as the 7 entries in `<constants>` (D-02/D-03). Both at the top, above any loop. No globbing anywhere in this script — a `*.lua` glob would sweep up emacs lock files named `.#Display.lua` from repo root (D-08 rationale).
4. Source preflight: `for` over `FILES`, and if any `"%SOURCE%<name>"` does not exist, print `ERROR: missing source file <name> in <SOURCE>` and `exit /b 1`. This is planner discretion beyond D-06 (see Deferred Questions Q3) and exists so a half-complete Phase 25 cannot produce a silent no-op deploy.
5. Counter `INSTALLED` initialised to 0.
6. Outer `for` over `FLAVORS`. Inside: test `if exist "%WOW_ROOT%\<flavor>\"` (trailing backslash = directory test). If absent, do nothing at all — no echo, no errorlevel change (D-05 / INST-02). If present: build `DEST` as `%WOW_ROOT%\<flavor>\Interface\AddOns\TerribleBuffTracker` into a delayed-expansion variable, `if not exist "!DEST!" mkdir "!DEST!"` (preserving today's behavior), then an inner `for` over `FILES` doing `copy /Y "%SOURCE%<file>" "!DEST!\" >nul` with an `if errorlevel 1` guard that echoes the failing file and destination and `exit /b 1`. Then `set /a INSTALLED+=1` and echo one line naming the destination (D-07 — one line per successful target). Use `!DEST!` / `!INSTALLED!` inside the loop body; `%SOURCE%`, `%FILES%`, `%FLAVORS%` and `%WOW_ROOT%` are loop-invariant and may use percent expansion, but always inside double quotes when they are paths.
7. After the loop: `if "!INSTALLED!"=="0"` print a diagnostic that names the exact root searched, lists the flavor directory names that were checked, and tells the user to set `TBT_WOW_ROOT` if WoW lives elsewhere — then `exit /b 1` (D-06 / INST-03). Use delayed expansion for the counter, not `%INSTALLED%`.
8. Happy path ends with the existing friendly line: `Done! /reload in WoW to load the addon.` (D-07).

Keep the happy path quiet and fast — this script runs after every edit. Copy output is suppressed with `>nul`; the only routine output is one line per target plus the closing line.

Do NOT: add any argument parsing (INST-01 is a hard constraint — the user rejected a flavor argument and a second script), glob directories with `_*_`, detect which flavor a folder is in order to copy only one TOC (D-04 — both TOCs go everywhere, the client picks by suffix), touch `scripts/release.bat` (D-12), or wire in `scripts/check-toc.ps1` (D-13 is optional and adds batch-side error handling for no gain here — skip it).
  </action>
