  <action>
Create new file `EditModeFrames.lua` with the following structure. Use `local _, ns = ...` namespace pattern.

**Container creation in `ns:InitEditModeFrames()`:**
- `CreateFrame("Frame", "TBTBarContainer", UIParent)` — SetSize(220, 1), SetFrameStrata("MEDIUM")
- `CreateFrame("Frame", "TBTBuffContainer", UIParent)` — SetSize(40, 40), SetFrameStrata("MEDIUM")
- Store as `ns.barContainer` and `ns.iconContainer` (per D-01)
- Call `ApplyEditModePositions()` to set initial anchor points

**ApplyEditModePositions() function:**
- If `ns.db.editModePositions == nil` (D-07 fresh install detection), write hardcoded defaults to DB immediately:
  - bars: point="CENTER", relativeTo="UIParent", relativePoint="CENTER", x=300, y=0
  - icons: point="CENTER", relativeTo="UIParent", relativePoint="CENTER", x=300, y=-80
- Read `ns.db.editModePositions.bars` and `.icons`, call `ClearAllPoints()` then `SetPoint(pos.point, pos.relativeTo, pos.relativePoint, pos.x, pos.y)` on each container
- Apply visibility from `ns.db.tbtVisible` — if false, `Hide()` both containers

**Drag handle creation via local `CreateDragHandle(container, labelText)` function:**
- Create child frame, anchor TOPLEFT to TOPLEFT and TOPRIGHT to TOPRIGHT of container, SetHeight(24)
- SetFrameLevel to container:GetFrameLevel() + 5
- Background texture: `CreateTexture(nil, "BACKGROUND")`, `SetAllPoints()`, `SetColorTexture(0, 0, 0, 0.5)`
- Border: `CreateFrame("Frame", nil, handle, "BackdropTemplate")`, `SetAllPoints()`, SetBackdrop with edgeFile="Interface\\Tooltips\\UI-Tooltip-Border" edgeSize=8, SetBackdropBorderColor(0.2, 0.6, 1.0, 0.8)
- Label: `CreateFontString(nil, "OVERLAY")`, SetFontObject(GameFontNormal), SetText(labelText), SetTextColor(1, 1, 1, 1), SetPoint("CENTER")
- `handle:Hide()` initially, return handle
- Create handles: `ns.barDragHandle = CreateDragHandle(ns.barContainer, "TerribleBuffTracker")` and `ns.iconDragHandle = CreateDragHandle(ns.iconContainer, "TerribleBuffTracker")`

**Edit Mode lifecycle:**
- Set `ns.editModeActive = false` at module level
- `EventRegistry:RegisterCallback("EditMode.Enter", function() ns:OnEditModeEnter() end, ns)`
- `EventRegistry:RegisterCallback("EditMode.Exit", function() ns:OnEditModeExit() end, ns)`

**ns:OnEditModeEnter():**
- Set `ns.editModeActive = true`
- For each container (barContainer, iconContainer): `SetMovable(true)`, `EnableMouse(true)`
- Set `OnMouseDown` script: if button == "LeftButton" then self:StartMoving() end
- Set `OnMouseUp` script: self:StopMovingOrSizing() (do NOT save positions here per UI-SPEC)
- Call `ns:ShowEditModeHandles()` which shows both drag handles
- Call `InjectSidebarCheckbox()` (first time only, guarded by `ns.tbtCheckboxInjected` flag)

**ns:OnEditModeExit():**
- Set `ns.editModeActive = false`
- For each container: `SetMovable(false)`, `EnableMouse(false)`, set OnMouseDown/OnMouseUp to nil
- Call `ns:SaveEditModePositions()` FIRST, then `ns:HideEditModeHandles()`

**ns:SaveEditModePositions():**
- Read `GetPoint(1)` from each container
- Write to `ns.db.editModePositions.bars` and `.icons` with the schema:
  ```
  { point = point or "CENTER",
    relativeTo = (relativeTo and relativeTo:GetName()) or "UIParent",
    relativePoint = relativePoint or "CENTER",
    x = x or 300, y = y or 0 }
  ```
- Use defaults 300/-80 for icons y fallback

**ns:ShowEditModeHandles() / ns:HideEditModeHandles():**
- Show/Hide both `ns.barDragHandle` and `ns.iconDragHandle`
- On Show: also ensure containers are visible (even if tbtVisible is false, Edit Mode should reveal them for positioning)

**InjectSidebarCheckbox() (local function, called once):**
- Guard: return if `ns.tbtCheckboxInjected` is truthy
- Guard: return if `EditModeManagerFrame` or `.AccountSettings` is nil
- Access `EditModeManagerFrame.AccountSettings.SettingsContainer.ScrollChild.BasicOptionsContainer`
- Guard: return if container is nil
- `CreateFrame("Frame", nil, container, "EditModeManagerSettingCheckButtonTemplate")`
- Set `checkButton.Label:SetText("TerribleBuffTracker")`
- Set `checkButton.isBasicOption = true`
- Wire callback function `onCheck(isChecked, isUserInput)`:
  - If `isUserInput`: write `ns.db.tbtVisible = isChecked`, Show/Hide both containers accordingly
  - Else: call `checkButton:SetControlChecked(isChecked)`
- `checkButton:SetControlChecked(ns.db.tbtVisible ~= false)` for initial state sync
- `container:Layout()` to force GridLayoutFrame reflow
- `ns.tbtSidebarCheckbox = checkButton`
- `ns.tbtCheckboxInjected = true`

Run `stylua EditModeFrames.lua` after writing.
