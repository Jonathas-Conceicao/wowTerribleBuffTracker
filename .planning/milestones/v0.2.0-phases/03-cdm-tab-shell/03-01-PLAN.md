Create CDMTab.lua in the addon root directory. This is the main Lua file for the CDM tab integration. Use `local _, ns = ...` namespace pattern.

Structure the file as follows:

**1. Initialization gate (Pattern 6):**
Use EventUtil.ContinueAfterAllEvents to gate all CDM interaction behind VARIABLES_LOADED, PLAYER_ENTERING_WORLD, and COOLDOWN_VIEWER_DATA_LOADED. Call ns:InitCDMTab() when all three have fired.

**2. ns:InitCDMTab() function — wires everything after CDM is ready:**

a) **Content panel creation (D-07, D-08, Pattern 4):**
   - Create "TBTSettingsPanel" frame parented to CooldownViewerSettings with BackdropTemplate
   - Anchor TOPLEFT(17, -72) and BOTTOMRIGHT(-30, 29) relative to CooldownViewerSettings (matches CooldownScroll geometry exactly)
   - Set backdrop: bgFile="Interface\\DialogFrame\\UI-DialogBox-Background", edgeFile="Interface\\DialogFrame\\UI-DialogBox-Border", tile=true, tileSize=32, edgeSize=16, insets={left=4, right=4, top=4, bottom=4}
   - SetBackdropColor(0, 0, 0, 0.9)
   - SetFrameLevel to CooldownViewerSettings:GetFrameLevel() + 10 (above CDM content)
   - Hide by default

b) **Scroll frame inside panel (D-07):**
   - Create ScrollFrame with ScrollFrameTemplate inside TBTSettingsPanel
   - Anchor TOPLEFT(0,0) BOTTOMRIGHT(-17, 0) inside panel
   - Create scroll child frame, set width to panel width minus 17, height=1
   - Store as ns.tbtScrollChild for Phase 4 to populate
   - Call scrollFrame.ScrollBar:SetHideIfUnscrollable(false) if that method exists (guard with if block)

c) **Tab click handler (Pattern 2, D-05):**
   Wire SetCustomOnMouseUpHandler on TBTSettingsTab. On LeftButton + upInside:
   - Call ns:ShowTBTPanel()
   - Loop CooldownViewerSettings.TabButtons, SetChecked(t == TBTSettingsTab) for each

d) **SetDisplayMode hook (Pattern 3, D-06):**
   hooksecurefunc(CooldownViewerSettings, "SetDisplayMode", function() ns:HideTBTPanel() end)
   This fires when user clicks Spells or Auras tab. Hides TBT panel and unchecks TBT tab.

e) **Preview hooks (D-15, D-16):**
   - Hook CooldownViewerSettings OnShow: call ns:StartAllPreviewTimers() to show preview bars/icons when CDM settings opens (any tab). Use HookScript("OnShow", ...) on CooldownViewerSettings.
   - Hook CooldownViewerSettings OnHide: call ns:ClearAllTimers() to stop previews when CDM settings closes. Use HookScript("OnHide", ...) on CooldownViewerSettings.

**3. ns:ShowTBTPanel() function:**
   - Hide CooldownViewerSettings.CooldownScroll (the CDM scroll frame)
   - Show TBTSettingsPanel
   - SetChecked(true) on TBTSettingsTab, SetChecked(false) on all other TabButtons

**4. ns:HideTBTPanel() function:**
   - Hide TBTSettingsPanel
   - Show CooldownViewerSettings.CooldownScroll
   - SetChecked(false) on TBTSettingsTab

**5. ns:SelectTBTTab() function (D-09, D-10, Pattern 5):**
   Called by /tbt slash command and internally. Opens CDM if not visible, then selects TBT tab:
   - If not CooldownViewerSettings:IsVisible() then CooldownViewerSettings:ShowUIPanel() end
   - Call ns:ShowTBTPanel()
   - Loop TabButtons, SetChecked(t == TBTSettingsTab) for each

CRITICAL per D-05: NEVER call CooldownViewerSettings:SetDisplayMode("tbt_buffs") anywhere. This will assertsafe crash.
