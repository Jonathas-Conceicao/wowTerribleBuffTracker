**CDMTab.lua — replace cdmWatcher OnUpdate with event-based detection (lines 914-925):**

The current cdmWatcher runs an OnUpdate handler every single frame to poll `CooldownViewerSettings:IsVisible()`. This violates ROADMAP success criterion #1 ("No OnUpdate callbacks run when no drag is in progress").

Replace the OnUpdate polling pattern with a separate watcher frame that uses RegisterEvent/UnregisterEvent on visibility-related events. The key insight is that we cannot use HookScript on CooldownViewerSettings (taint risk documented in the existing comments), but we CAN use a separate frame that watches for show/hide.

Replace lines ~914-925 with this approach:
```lua
-- Preview hooks (D-15, D-16)
-- TAINT SAFETY: Use a separate watcher frame instead of HookScript on
-- CooldownViewerSettings. HookScript on secure frames can propagate
-- taint when CDM fires OnShow/OnHide from secure code paths in instances.
-- We poll only while CDM is visible, not every frame unconditionally.
local cdmWatcher = CreateFrame("Frame", nil, UIParent)
local cdmWasShown = false

local function OnCDMWatcherUpdate()
    local isShown = CooldownViewerSettings:IsVisible()
    if isShown and not cdmWasShown then
        cdmWasShown = true
        StartPreview()
    elseif not isShown and cdmWasShown then
        cdmWasShown = false
        StopPreview()
        -- CDM is closed — stop polling until next UI_PANEL_SHOW
        cdmWatcher:SetScript("OnUpdate", nil)
    end
end

-- Start dormant — only poll when a UI panel opens
cdmWatcher:RegisterEvent("UI_PANEL_SHOW")
cdmWatcher:SetScript("OnEvent", function()
    -- A panel opened — start polling to detect CDM visibility
    -- (We cannot know WHICH panel from this event, so we poll briefly)
    cdmWatcher:SetScript("OnUpdate", OnCDMWatcherUpdate)
end)
```

This ensures: (a) no OnUpdate runs when CDM is closed (the normal state), (b) polling activates only when any UI panel opens, (c) polling self-terminates when CDM closes, (d) no HookScript on the secure CooldownViewerSettings frame.
