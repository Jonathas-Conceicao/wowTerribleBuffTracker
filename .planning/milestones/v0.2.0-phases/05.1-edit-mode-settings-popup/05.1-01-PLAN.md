Refactor Display.lua to replace the hardcoded `cachedBarSettings` and `cachedIconSettings` module-level tables with DB-backed values per D-10. Use a `RefreshContainerSettings()` approach to avoid per-frame table allocation (preserving the zero-GC hot path pattern from CLAUDE.md).

1. Remove the hardcoded `cachedBarSettings` table literal (lines 19-29) and `cachedIconSettings` table literal (lines 31-41). Replace with empty table declarations:
```lua
local cachedBarSettings = {}
local cachedIconSettings = {}
```

2. Add a `RefreshContainerSettings()` function that reads from `ns.db.containerSettings` and populates the module-level cached tables. This function translates DB field names/units to the internal field names used by ShouldShow/ApplyBarStyle:
```lua
local function RefreshContainerSettings()
    local bs = ns.db and ns.db.containerSettings and ns.db.containerSettings.bars
    if bs then
        cachedBarSettings.iconScale        = (bs.scale or 100) / 100
        cachedBarSettings.iconPadding      = bs.padding or 5
        cachedBarSettings.barWidth         = bs.barWidth or 220
        cachedBarSettings.alpha            = 1
        cachedBarSettings.visibleSetting   = (bs.visibility == 2) and 1 or (bs.visibility == 3) and 2 or 0
        cachedBarSettings.barContent       = 0
        cachedBarSettings.hideWhenInactive = (bs.visibility == 1)
        cachedBarSettings.timerShown       = true
        cachedBarSettings.tooltipsShown    = true
    end

    local is = ns.db and ns.db.containerSettings and ns.db.containerSettings.buffs
    if is then
        cachedIconSettings.orientationSetting = is.orientation or 0
        cachedIconSettings.iconDirection      = is.growthDirection or 0
        cachedIconSettings.iconScale          = (is.scale or 100) / 100
        cachedIconSettings.iconPadding        = is.padding or 5
        cachedIconSettings.alpha              = 1
        cachedIconSettings.visibleSetting     = (is.visibility == 2) and 1 or (is.visibility == 3) and 2 or 0
        cachedIconSettings.hideWhenInactive   = (is.visibility == 1)
        cachedIconSettings.timerShown         = true
        cachedIconSettings.tooltipsShown      = true
    end
end
```

3. Expose `RefreshContainerSettings` on the namespace so the settings popup can call it after changing a value:
```lua
ns.RefreshContainerSettings = RefreshContainerSettings
```

4. Call `RefreshContainerSettings()` once at the end of `ns:InitDisplay()` to populate the cached tables on startup.

5. The visibility mapping from the new 4-value DB field to the old ShouldShow parameters:
   - visibility=0 (Always): visibleSetting=0, hideWhenInactive=false
   - visibility=1 (Active Only): visibleSetting=0, hideWhenInactive=true  (current default)
   - visibility=2 (In Combat): visibleSetting=1, hideWhenInactive=false
   - visibility=3 (Hidden): visibleSetting=2, hideWhenInactive=false

6. ShouldShow function itself does NOT change — it still receives the same field names from the cached tables. No other changes to UpdateDisplay or ApplyBarStyle.
